# 錢，的趣味 - 專為台灣失智症長者設計的認知刺激活動

![專案主畫面](https://github.com/user-attachments/assets/68b21a26-4d2f-4e0e-bd46-0cf351bb47c7)

這是一個開源、可直接在瀏覽器中運行的互動式網頁應用程式，專為在失智症據點、長照機構帶領團體活動的醫護人員、社工、志工及家屬所設計。

本專案的靈感源自於認知刺激治療（Cognitive Stimulation Therapy, CST），透過在地化、懷舊的「金錢」主題，旨在為台灣的失智症長輩提供一個充滿樂趣、尊重且富有尊嚴的認知訓練工具。

## 專案緣起

我們注意到，許多為失智症設計的活動資源較少考慮到台灣長輩的在地文化與共同記憶。本專案的初衷，便是將實證有效的CST原則，與台灣長輩最熟悉的生活經驗相結合，創造出一套真正「接地氣」的非藥物性輔助活動。

我們從一個關於「金錢使用」的單一活動發想，經過多次的迭代與優化，最終發展成這個包含多個主題模組、題庫豐富且介面友善的互動遊戲。

## ✨ 特色亮點

* **專為長者優化的 UI/UX**：採用超大字體、高對比度的色彩、以及簡單直觀的點擊操作，完全為長輩的視覺與使用習慣進行優化，非常適合在投影幕上進行團體活動。
* **豐富的台灣在地化內容**：題庫圍繞著台灣長輩的共同記憶，涵蓋了「菜市場」、「廟口小吃」、「懷舊柑仔店」等主題，能有效引發參與和共鳴。
* **兩種彈性的活動模式**：
    1.  **價格猜謎**：透過選擇題的方式，讓長輩對物品價格進行有趣的猜測與討論。
    2.  **引導式問答**：在「舊時光的薪水袋」單元中，以開放式問題引導長輩分享個人生命故事與回憶，深化情感連結。
* **零安裝，易於部署**：整個應用程式只有一個 `index.html` 檔案，無需安裝任何軟體，可以直接在網頁瀏覽器中運行，也能輕易地部署到免費的 GitHub Pages 服務上。
* **穩定流暢的操作體驗**：程式邏輯經過多次修正與壓力測試，確保在活動帶領者快速點擊操作時，依然能保持流暢穩定，不會卡頓。

## 活活動模組介紹

本遊戲包含五大主題模組，您可以根據當天長輩的興趣與狀況，自由選擇：

1.  **🥬 熱鬧菜市場**：猜測青菜、豬肉、魚等日常食材的價格。
2.  **🍜 廟口小吃攤**：圍繞蚵仔麵線、臭豆腐等台灣經典小吃的價格問答。
3.  **🍬 懷舊柑仔店**：回味民國七十年代的王子麵、黑松汽水、愛國獎券等懷舊商品。
4.  **🏠 生活大小事**：涵蓋電影票、紅包、大同電鍋等與生活息息相關的物品。
5.  **🪙 舊時光的薪水袋**：引導式問答，從舊版新台幣開始，聊到第一份薪水與賺錢的快樂。

## 🚀 如何使用

1.  **直接遊玩**：點擊此連結即可開始遊戲：[https://thc1006.github.io/taiwan-dementia-friendly-cst-activity/](https://thc1006.github.io/taiwan-dementia-friendly-cst-activity/)
2.  **活動帶領步驟**：
    * 將遊戲畫面投影到大螢幕上。
    * 點擊「開始遊戲」，進入主題選擇頁面。
    * 選擇一個今天想帶領的主題。
    * 根據畫面上的題目與圖片，引導長輩進行回答與討論。
    * 點擊「下一題」或「下一頁」繼續活動。

## 🛠️ 如何部署到您自己的 GitHub

如果您想擁有自己的一份，或是想自行修改題目，可以依照以下步驟：

1.  **下載檔案**：點擊本儲存庫右上角的 `Code` -> `Download ZIP`，下載所有檔案。
2.  **建立儲存庫**：在您自己的 GitHub 帳號下建立一個新的儲存庫（Repository）。
3.  **上傳檔案**：將下載並解壓縮後的 `index.html` 等檔案，上傳到您剛建立的儲存庫中。
4.  **啟用 GitHub Pages**：在儲存庫的 `Settings` -> `Pages` 頁面，將 `Source` 設置為 `Deploy from a branch`，並選擇 `main` 分支的 `/root` 資料夾，然後點擊 `Save`。
5.  稍待幾分鐘後，您的專屬版本就部署完成了！
